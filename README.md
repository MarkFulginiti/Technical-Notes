# Technical Notes

This repository contains compact technical notes, short papers, simulation studies, and reproducible code focused on how statistical methods behave when real-world data violate ideal assumptions. The emphasis is on data-generating mechanisms, estimator behavior, method comparison, practical consequences, and reproducible examples across applied statistics, causal inference, modeling, computation, probability, and related quantitative workflows. Some notes also serve as exploratory simulation studies for longer-term research on estimator behavior under violated assumptions.

The notes are organized by field and method.
